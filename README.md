# Work portfolio

This is a Vite + React + TypeScript for displaying my work experience and projects that I've done.

**Live site:** [troycalaquian.com](https://troycalaquian.com)

## Features

- Interactive animated background (canvas particle network that reacts to the cursor)
- Terminal-style boot sequence and typewriter intro
- Page transitions powered by GSAP
- Light and dark mode
- Searchable projects page
- Responsive layout

## Tech Stack

- **Framework:** React, TypeScript, Vite
- **UI:** Mantine
- **Animation:** GSAP
- **Routing:** React Router
- **Deployment:** Vercel

# Installing dependencies

After cloning the project, use `npm install` to instal dependencies

# Running the project

Use the following command to run the project: `npm run dev`

## Project Structure

- `src/pages` – route-level pages (Home, About, Projects, Contact) and the shared layout
- `src/components` – reusable components (background, boot sequence, CTA, etc.)
- `src/hooks` – custom hooks for animations and navigation
- `src/helper` – theme configuration and project/skill data
